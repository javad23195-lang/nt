# سامانه نت — یادداشت فنی پروژه

این پوشه کد سازنده `سامانه-نت.html` و آزمایش‌های آن است. هر تغییر در سامانه باید از همین‌جا شروع شود، نه با دست‌کاری مستقیم فایل نهایی.

> مخزن عمومی است. **هرگز** کلید GitHub، رمز اطلاعات، رمز ۶ رقمی، کد اتصال یا نام افراد را در این مخزن ننویسید.

## کاربر و روش کار
- کاربر: مهندس واحد نگهداری و تعمیرات (نت) یک معدن. همه گفتگو به **فارسی**، کوتاه و مناسب گوشی.
- **قبل از هر تغییر بزرگ، طرح و مثال بده** و تأیید بگیر. تغییر کوچک را مستقیم انجام بده.
- **آزمایش داخل خود سامانه** (نه فقط فرم جدا). همه آزمایش‌ها باید موفق باشند.
- نام کالاها دقیقاً مثل کاتالوگ انبار باشد (مثلاً «روغن دیزل اتوماتیک 50-20»).
- تحویل: فایل `سامانه-نت.html`. کاربر آن را در صفحه آپلود GitHub می‌گذارد (`/upload/main`، دکمه Commit changes). نام فایل باید دقیقاً همین باشد (بدون «(1)»).
- آدرس سامانه: `https://javad23195-lang.github.io/nt/سامانه-نت.html` (لینک با درصدها رمزگذاری می‌شود).

## ساختار فایل نهایی
یک صفحه HTML (پوسته) با نوار زبانه‌ها. هر زبانه یک فرم HTML کامل است که به شکل base64 در آرایه `const DOCS = [{name,icon,color,b64}, ...]` قرار دارد و در یک `iframe` با `srcdoc` باز می‌شود. ۹ زبانه:

امروز · برنامه روزانه · دفترچه قرائت · ثبت مشکلات · شناسنامه · خدمات · انبار · درخواست خرید · توقف شیفت

همه اطلاعات در `localStorage` مرورگر است (کلیدهای `nt_*`). مهم‌ترین‌ها:

| کلید | زبانه |
|---|---|
| `nt_prog_v1`, `nt_prog_rules_v1` | برنامه روزانه |
| `nt_daftar_v1` (آرایه `{dev,unit,val,date}`) | دفترچه قرائت (خدمات هم می‌نویسد) |
| `nt_moshkel_v1` | ثبت مشکلات |
| `nt_sh8_v1` … | شناسنامه |
| `nt_khadamat_v1` … | خدمات |
| `nt_anbar_out_v1`, `nt_anbar_in_v1`, `nt_anbar_sent_v1`, `nt_anbar_codes_v1` | انبار |
| `nt_kharid9_v1`, `nt_kharid_cat_v1` … | درخواست خرید |
| `nt_tavaqof_v1` (کلید «تاریخ\|شیفت» → `{stops:[{id,dev,from,to,cause,note,by}],sent}`) | توقف شیفت |
| `nt_today_todo_v1`, `nt_fixed_done_v1` | امروز |
| `nt_users_v1`, `nt_seen_v1` | لیست کاربران و «آخرین اتصال» |

کلیدهای `ntsync_*` تنظیم همگام‌سازی همان سیستم است و ارسال نمی‌شود.

## ساخت
```
_dev/build.sh          # خروجی: _dev/out.html
```
مراحل:
1. `src/base-user-1047.html` — نسخه کاربر (۸ زبانه) پیش از کارهای همگام‌سازی.
2. `src/patch_daftar.py` — «ورود لیست قرائت (چسباندن)» در دفترچه قرائت.
3. `src/add_tavaqof.py` + `src/tavaqof-src.html` — زبانه «توقف شیفت».
4. `src/add_report.py` — کارت «گزارش اکسل» در زبانه امروز.
5. `src/build.py` — `sync.css`، `sync.js` و `report.js` را به پوسته اضافه می‌کند و چند جای پوسته را وصله می‌کند.

برای تغییر یک فرم: یک اسکریپت وصله مثل `patch_daftar.py` بنویس (base64 را باز کن، `rep(a,b)` با کنترل تعداد، دوباره base64). برای دیدن فرم‌ها: `NT_DOCS=/tmp ./build.sh`.

## همگام‌سازی (`src/sync.js`)
- اطلاعات مشترک: پرونده `nt-data.json` در **برچسب** `nt-data` همین مخزن (نه شاخه main).
- قفل: AES-GCM؛ کلید از رمز اطلاعات با PBKDF2-SHA256 (۱۵۰٬۰۰۰ دور)؛ پیش از قفل gzip.
- ارسال: blob → tree → commit (والد = نسخه فعلی) → `PATCH refs/tags/nt-data` بدون force (اگر کسی زودتر فرستاده باشد خطای fast-forward → ادغام و تلاش دوباره). هر ۳۰ ارسال یک‌بار تاریخچه با force دور ریخته می‌شود.
- خواندن همیشه با **شناسه commit** (`contents?ref=<sha>`)، چون خواندن با نام برچسب گاهی نسخه قبلی را می‌دهد.
- ادغام سه‌طرفه (پایه = `ntsync_base_v1`): ردیف تازه هر دو طرف می‌ماند؛ حذف اعمال می‌شود؛ اصلاح هم‌زمان یک ردیف → هر دو نسخه + پیام. شناسه ردیف: `id`، برای دفترچه `dev|date`. کلیدهای محاسبه‌ای (`CALC`) ادغام نمی‌شوند.
- زبانه‌ای که کاربر در آن مشغول نوشتن است دوباره بارگذاری نمی‌شود (حداکثر ۳ دقیقه صبر).
- زمان‌ها: ارسال ۳ ثانیه بعد از ثبت، حداقل ۴۰ ثانیه بین دو ارسال، بررسی هر ۲۰ ثانیه، و ارسال فوری هنگام بستن صفحه.
- نقش‌ها: **مدیر** (با کلید GitHub تنظیم شده، همه چیز، مدیریت کاربران) · **کاربر** (با «کد اتصال» + رمز ۶ رقمی؛ دسترسی هر زبانه: ثبت / فقط مشاهده / پنهان، از `nt_users_v1`؛ «آخرین اتصال» هر ۱۵ دقیقه) · **مشاهده با رمز اطلاعات** (بدون ارسال).
- کد اتصال: `NT1.<salt>.<iv>.<ct>` (base64url)؛ داخلش کلید و رمز اطلاعات، قفل‌شده با PBKDF2(رمز ۶ رقمی، ۴۰۰٬۰۰۰ دور). لینک: `…html#join=<کد>`.
- قفل ورود: سیستم وصل‌نشده هیچ زبانه‌ای نمی‌بیند (فقط اگر اطلاعات مشترکی وجود نداشته باشد باز می‌شود).
- «قطع دسترسی» یا «حذف» کاربر: اطلاعات از سیستم او پاک می‌شود. «قطع قطعی»: تعویض کلید و رمز.

## گزارش اکسل (`src/report.js`)
- دکمه در زبانه «امروز» → پیام `{nt:'report'}` → پنجره در پوسته (بازه: این ماه، ماه قبل، دلخواه؛ انتخاب برگه‌ها؛ تعداد ردیف هر بخش).
- برگه‌ها: خلاصه توقف (هر دستگاه + هر علت)، توقف‌ها، کارکرد دستگاه‌ها (آخرین قرائت پیش از بازه تا آخرین قرائت در بازه)، قرائت، خروج انبار، ورود انبار، درخواست خرید، خدمات، مشکلات. بخش زبانه‌های پنهان کاربر حذف می‌شود.
- گروه علت توقف: فهرست `BROKEN` = «خرابی»، بقیه = «سالم ولی کار نکرد» (همان فهرست فرم توقف).
- کتابخانه: SheetJS 0.18.5 (Apache-2.0) در `lib/xlsx.mini.min.js`؛ فقط هنگام ساخت فایل بارگذاری می‌شود (پشتیبان: jsdelivr). فقط نوشتن؛ فایل ناشناس خوانده نمی‌شود.
- نام فایل لاتین است (`NT-report-…xlsx`)، چون نام فارسی در بعضی مرورگرها «download» ذخیره می‌شود.
